# 🎾 ДТ — Telegram Mini App теннисного клуба

Мини-приложение для клуба «ДТ»: расписание занятий, свободная игра (аренда кортов),
магазин экипировки и раздел о клубе. Визуальный язык — iOS-экосистема (крупная
типографика, сгруппированные списки, стеклянный таб-бар, bottom sheet), палитра —
белый «клэй» + теннисный зелёный с текстурами корта, мяча и зерна.

## Стек и хостинг

TypeScript + React 19 + Vite 8, деплой на **Vercel**, база — **Neon (PostgreSQL)**,
вход — из **Telegram Apps** (мини-апп открывает сайт, `initData` проверяется на сервере).
Подробная инструкция по связке: [`docs/DEPLOY.md`](docs/DEPLOY.md).

## Запуск локально (без Vercel и Neon)

```bash
npm install
npm run dev      # http://localhost:5173 — сайт + эмулятор /api (данные из src/data)
```

Локально те же маршруты `/api/*` обслуживает `server/preview-api.ts`: корты, тренеры,
занятия, окна, товары и брони работают как на проде, но хранятся в `.preview/db.json`.
Предпросмотр — эмулятор: он не подключает рабочую базу или Telegram-бота.

| Команда | Что делает |
| --- | --- |
| `npm run dev` | Vite dev-сервер на `0.0.0.0:5173` |
| `npm run build` | типы (`tsc --noEmit`) + production-сборка в `dist/` |
| `npm run preview` | предпросмотр собранной версии на `0.0.0.0:4173` |
| `npm run typecheck` | только проверка типов |
| `npm run smoke` | production-бандл в jsdom, ошибки входа и полный поток через реальные API + PGlite (после сборки) |
| `npm run test:security` | PGlite-проверки бронирования, авторизации, ролей и бота |
| `npm run test:postgres` | опциональные проверки гонок на отдельной локальной PostgreSQL; см. `docs/DEPLOY.md` |

## Разделы

| Раздел | Что внутри |
| --- | --- |
| **Клуб** | герой с фото корта, ближайшая запись, быстрые действия, сетка «скоро в клубе», тренеры, абонемент, инфраструктура |
| **Занятия** | сетка на 30 дней, фильтры по формату (группа / сплит / дети / индивидуально / корт-фитнес), запись через bottom sheet, «свой урок» с выбором тренера, уровня, дня и времени |
| **Игра** | свободная аренда кортов по дням и кортам, сетка свободных окон, отметка своей брони |
| **Магазин** | каталог по категориям, избранное, карточка товара, количество, оформление заказа, список заказов |
| **О нас** | фото клуба, статистика, команда, мои записи с отменой, FAQ, контакты |

Записи и заказы идут через API: в production — `Vercel + Neon`, привязаны к Telegram-аккаунту. Открывайте Mini App из inline-кнопки или меню в личном чате бота. При открытии адреса в обычном браузере вместо интерфейса показывается инструкция; старый вход по идентификатору устройства удалён. При ошибке API не показываются вымышленные данные, а локальный `npm run dev` использует отдельный демо-эмулятор.

**Перед выпуском для игроков нужен аудит старых гостей:** их идентификаторы могли совпасть с Telegram ID. При таком совпадении старые записи или контакты могут быть видны другому пользователю; автоматически разделить их по ID нельзя. Данные не удалялись и не исправлялись. Сначала необходимы резервная копия и согласованный план аудита.

## Дизайн-система

- Цвета, радиусы, тени, тайминги и текстуры — только в `src/styles/tokens.css`.
- Текстуры: `--texture-court-lines` (разметка корта), `--texture-grain` (белая глина),
  `--texture-felt` (пушок мяча). Никаких внешних картинок для фонов.
- Фото — сгенерированные ассеты в `public/img/` (корт, лаундж, ракетка, мячи, худи).
- Теннисные акценты: разметка корта в герое и клубной карте, мяч с пушком в блоке
  аренды, лаймовые бейджи и «шов» мяча в пустых состояниях.

## Telegram

`src/lib/telegram.ts` подключает официальный WebApp SDK (expand, тема, haptics).
На входе сервер проверяет сырое `initData` (HMAC, не старше 10 минут) и выдаёт
сессию на 2 часа; она хранится только в памяти и привязана к origin. После
истечения нужно закрыть Mini App и открыть его снова. Токен сессии не следует
передавать другим людям: он пригоден для повторного использования до истечения.

Бот работает в личных чатах и разделяет роли по `ADMIN_TELEGRAM_IDS`: администратор получает панель, остальные — меню с расписанием, своими записями и заказами. Игрок может отменить свою будущую запись; создание брони и заказа — в Mini App. Новые кнопки открывают его через `web_app`. Для обновления кнопки меню и команд без переустановки webhook есть `/api/bot/setup?mode=menu`; порядок настройки и безопасной миграции — в `docs/DEPLOY.md`.

## Переменные окружения

Список — в `.env.example`. Ключевые: `DATABASE_URL` (Neon), `TELEGRAM_BOT_TOKEN`
(только сервер, без префикса `VITE_`), `VITE_APP_URL`, `VITE_ADMIN_BOT_URL`.
Секреты живут в панели Vercel, в репозиторий не попадают.

## Ограничения текущей версии

- Онлайн-оплаты нет: заказ создаётся со статусом `reserved`, оплата на ресепшене.
- Подпись Telegram не подтверждает телефон и не исключает спам с разных аккаунтов; лимиты по истории не защищают от параллельных и распределённых запросов.
- На дальние дни доступны только окна и занятия, которые администратор добавил в боте (повтор до 30 дней).
- Уведомления за 2 часа не отправляются: нужна cron-функция после подключения токена.
- Скриншоты в песочнице не снимались (нет системных библиотек браузера); проверка —
  типы, сборка и локальные jsdom/API-тесты. Мобильный Telegram и рабочая Neon не проверены.

Подробности ограничений и точки роста: [`docs/IMPROVEMENTS.md`](docs/IMPROVEMENTS.md).
